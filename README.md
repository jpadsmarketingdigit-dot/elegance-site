# Elegance Cleaning Services: website

Site of Elegance Cleaning Services (house, carpet and upholstery cleaning in Southeastern Massachusetts and Rhode Island).

- `index.html`: the whole site (pages, price calculator, service area map)
- `assets/`: photos, logo, map and translations (`i18n.js`, EN / ES / PT)

## Editing
- Prices: `HOUSE` and `CARPET` objects at the top of the main script in `index.html`
- Phone: `BUSINESS` object in the same place
- Cities on the map: `CITIES` and `AREA`
- Translations: `assets/i18n.js` (key = English text)

## Publishing with GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch `main` / root → Save.
